## 🚀 Featured Projects

### ⚖️ CodeGavel: Coding Practice & Learning Platform
`Java` `Spring Boot` `React` `MySQL` `Redis` `Docker` `JWT` · *In active development*

Started as an online code judge and is growing into a platform for coding practice and CS learning.

- Evaluates submitted Java code with verdicts: Accepted, Wrong Answer, Runtime Error, Compilation Error, Time Limit Exceeded
- Runs code in Docker containers with resource limits and network restrictions
- Redis-backed background processing; Spring Security + JWT for authentication
- React UI with the Monaco Editor; guided lessons and algorithm visualizations in progress

### 📄 ResumeLens: AI Resume Matcher
`Java` `Spring Boot` `React` `Gemini API` `JUnit 5`

Compares a resume against a job description to surface matched and missing skills, with AI-assisted suggestions for improving resume bullets.

- Supports PDF, DOCX, and TXT resumes
- Word-boundary matching to tell apart skills like Java and JavaScript
- Validates structured AI responses, includes a fallback, and covers edge cases with JUnit 5 tests

### 👥 Employee Management System
`Java` `JDBC` `MySQL` `HikariCP` `JUnit` `Maven`

A database-backed app for employee CRUD and department reporting, with separate model, DAO, service, and UI layers.

- Transactional department reassignment and parameterized queries
- Department-level headcount, salary, and payroll reports
- Pooled database connections and a JUnit-tested service layer

### ✅ TaskFlow: Task Manager
`HTML` `CSS` `JavaScript`

A responsive task dashboard in vanilla JavaScript with task CRUD, categories, priorities, search, date filters, `localStorage` persistence, live statistics, and a weekly analytics chart.
